نشر موقع ALMURADI SOFT ERP برابط عام
====================================

مهم: هذا الملف يشرح النشر؛ لا ينشئ رابطًا عامًا تلقائيًا. يجب أن تنشر من حساب الاستضافة الخاص بك.

الطريقة المقترحة: Render + GitHub
1. أنشئ مستودع GitHub جديدًا وارفع ملفات المشروع دون مجلد .venv أو قاعدة بيانات almuradi.db.
2. افتح https://render.com وسجّل الدخول.
3. أنشئ Web Service واربطه بمستودع GitHub.
4. Build Command: pip install -r requirements-prod.txt
5. Start Command: gunicorn app:app --workers 2 --bind 0.0.0.0:$PORT --timeout 120
6. Health Check Path: /health
7. أضف قرصًا دائمًا إلى /var/data، واجعل DATABASE_PATH=/var/data/almuradi.db.
8. أضف APP_SECRET_KEY كقيمة سرية طويلة عشوائية وSESSION_COOKIE_SECURE=1.
9. عيّن INITIAL_ADMIN_PASSWORD إلى كلمة مرور قوية تعرفها، ولا تترك كلمة مرور افتراضية.
10. بعد النشر، افتح الرابط الذي يعرضه Render، ثم اختبر /health وتسجيل الدخول والفواتير والنسخ الاحتياطي.

قبل الاستخدام العام:
- لا تستخدم قاعدة SQLite واحدة على عدة نسخ/خوادم متوازية أو مشاركة شبكية.
- قيّم PostgreSQL للإنتاج متعدد المستخدمين، مع نسخ احتياطي مجرّب ومراقبة.
- استخدم HTTPS، كلمة مرور مدير قوية، وغيّر مفاتيح الأسرار قبل النشر.
- اختبر كل عمليات CRUD والصلاحيات والحسابات والتقارير؛ لا تعتبر التقارير قانونية/ضريبية معتمدة دون مراجعة محاسب مختص.
