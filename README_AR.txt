ALMURADI SOFT ERP — دليل التشغيل
=================================

المتطلبات:
- Windows 10/11
- Python 3.11 أو أحدث (تأكد من خيار Add Python to PATH)
- اتصال إنترنت عند التثبيت الأول لتنزيل المكتبات

التشغيل من قائمة الاختيار:
1) انقر RUN_MENU.bat
2) اختر 1 لتطبيق سطح المكتب داخل نافذة مستقلة (يتطلب pywebview)، أو 2 لتشغيل الموقع المحلي في المتصفح.

التشغيل المباشر:
- RUN_DESKTOP.bat: نافذة سطح مكتب مستقلة.
- RUN_SYSTEM.bat: موقع ويب محلي على http://127.0.0.1:8000.
- BUILD_EXE.bat: يبني إصدار Windows EXE داخل dist\ALMURADI_SOFT_ERP\.

الدخول المحلي الأول:
اسم المستخدم: admin
كلمة المرور الافتراضية: ChangeMe123!
غيّرها فورًا قبل الاستخدام الحقيقي. هذه النسخة تحتاج إلى استكمال شاشة تغيير كلمة المرور وإدارة الاستعادة قبل النشر العام.

الوحدات الحالية تتضمن لوحة التحكم، دليل الحسابات، الأصناف وحركات المخزون، العملاء والموردين، فواتير المبيعات والمشتريات، المصروفات، القيود اليومية المتوازنة، التقارير الأولية، المستخدمين، سجل التدقيق، تفضيلات الواجهة، وتصدير CSV ونسخة قاعدة البيانات.

تنبيهات صريحة:
- قاعدة البيانات المحلية: almuradi.db داخل مجلد المشروع. نسخة EXE تحفظها في %LOCALAPPDATA%\ALMURADI_SOFT_ERP.
- واجهة سطح المكتب هي نافذة pywebview تعرض واجهة Flask المحلية؛ ليست واجهة Qt أصلية بالكامل.
- نسخة الويب المحلية لا تعني أنها متاحة للإنترنت. اتبع DEPLOY_WEB_AR.txt للحصول على رابط عام.
- النظام ليس منتجًا محاسبيًا معتمدًا بعد. الفواتير والمصروفات لا تُرحّل تلقائيًا إلى دفتر اليومية ولا تُحدّث المخزون من الفاتورة حتى الآن. راجع الحسابات والتقارير قبل الاستخدام المالي.
- لا توجد ضمانة بأن كل الأزرار أو الحالات تعمل بلا أخطاء قبل اختبار عملي على جهازك. جرّب نسخة احتياطية واستعادة بيانات قبل إدخال بيانات حقيقية.


تحسينات الهوية البصرية (إصدار تجريبي محسّن):
- شاشة ترحيب أولية تحمل اسم شركة المرادي سوفت وبيانات التواصل قبل تسجيل الدخول.
- شعار SVG مضمّن داخل static/logo.svg ويُستخدم كأيقونة للمتصفح والواجهات.
- تحسينات عامة للأزرار وحقول الإدخال والتركيز بلوحة المفاتيح.
- تفضيلات الثيم واللون موجودة في الإعدادات، وتُحفظ في الجلسة حسب التنفيذ الحالي.

مهم قبل الاستخدام الفعلي:
- هذه الحزمة تطوير للملف المرفق وليست اعتمادًا محاسبيًا نهائيًا. راجع وحدات الفواتير والترحيل والمخزون والتقارير واختبرها ببيانات تجريبية قبل الاستخدام المالي.
- شاشة الترحيب مضافة، أما الترجمة الكاملة لكل النصوص إلى الإنجليزية، وتطبيق الثيم على كل عنصر في كل صفحة، والتحديث الآمن التلقائي، فتحتاج دورة تطوير واختبار إضافية ولم تُعتمد في هذه الحزمة على أنها مكتملة.
- لا تنشر النظام على الإنترنت قبل ضبط APP_SECRET_KEY وكلمات المرور والصلاحيات والنسخ الاحتياطي وHTTPS.
